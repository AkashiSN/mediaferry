## なぜ捨てないのか

**この 3 つは、ここにしか無いからです。**

1. **変異試験の記録。** どの変異が検出できて、どれが構造的に検出できないかを
   1 件ずつ書いてあります。**「このテストは冗長だから削ってよい」と判断する前に
   読むもの**です（対で壊せば検出できる冗長は、意図であって無駄ではありません）。
2. **レビューの記録。** 30 巡ぶんの指摘と、それを妥当と判断した根拠、退けた根拠が
   残っています。同じ層をもう一度触るときに、何が見落とされやすいかが分かります。
3. **試したが採らなかった案とその理由。** 「なぜ別のやり方にしなかったか」は
   仕様書には書かれません。

- **「次にやること」「未着手」といった記述は当時のものです。** 現在地は
  [`../development.md`](../development.md) を見てください
- **`HANDOFF.md` や `docs/phaseN-plan.md` への参照が出てきます。** 前者は
  [`../development.md`](../development.md) と [`../decisions.md`](../decisions.md) に
  分かれ、後者はこのディレクトリに移りました
- ここに書かれた判断が現在も有効かどうかは、[`../decisions.md`](../decisions.md)
  が正です。**食い違ったら `decisions.md` を信じてください**
