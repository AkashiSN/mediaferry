# 既知の制限

**分かっていて、まだ直していないことの一覧です。** 症状から引けるように並べて
あります。ここに無い症状は
[使い方ガイドの「困ったとき」](user-guide.md#困ったとき)を先に見てください。

内部の詳細（どのファイルのどの判断か、なぜ後回しにしたか）は
[`history/carryover.md`](history/carryover.md) にあります。

## 動かなくなる・詰まる

| 症状 | 何が起きているか | どうするか |
| --- | --- | --- |
| **スキャンが失敗すると、そのままでは数え直さない** | 「このカードについて数え始めた」印は**ジョブが走る前**に付きます。失敗しても印は残るので、同じ接続では自動では積み直されません | **カードを抜き挿しする**か、カードの中身の画面から手で数え直します |
| **走っている作業がホームに出ないことがある** | 作業の履歴は新しい順に 50 件で切れます。**終わった作業も枠を食う**ので、50 件並ぶと走っている作業が枠から落ちます | そのカードが「やること」に戻り「いま取り込む」が押せてしまいます。**作業の履歴（設定 › 記録）で実際の状態を確かめてください** |
| **リセットが「回収待ちの取り込みがある」と断る** | 回収できなかった取り込みの控えを**表示する画面がありません**（件数はホームに出ます） | アプリを再起動すると回収を試み直します |

## 表示が実態と食い違う

| 症状 | 何が起きているか |
| --- | --- |
| **「先に誰かが Immich へ上げていた写真です」と出るが、心当たりが無い** | 「**こちらが送ったと確かめられなかった**」場合も同じ文言で出ます。送信の直後にアプリが落ちると起きます。ほとんどの場合は自分で上げたものです |
| **Immich の説明欄に `default` と入っている** | **DJI が EXIF の説明欄に `default` と書いています。** mediaferry は説明を一度も送っていません。DJI で撮る限り毎回付きます |
| **つなぐ画面で毎回「つなぎ目に空白があります」と出る** | 空白が 0 より大きいと警告する作りですが、**実際のカードでは必ず 0 より大きくなります**。パート間の差が数十ミリ秒でも出ます |
| **「まだ送っていない」で絞ると、組の写真が黒いタイルで出る** | RAW+JPEG の組で**片方だけが未送信のとき**（Immich 側で片方を消した後など）、タイルはその未送信の 1 枚で組み立てられます。**RAW にはサムネイルが無いので黒く出ます**が、札は `JPG+RAW` のままなので組ごと未送信に見えます。**どちらが未送信なのかは、タイルを開いて「この 1 枚を作っているファイル」を見るまで分かりません。** そのまま送っても、送信済みの方は二重に上がりません |
| **さっき取り込んだものの並びが毎回変わる** | まとめて取り込んだぶんは取り込み時刻が同じになり、その中の並びが決まっていません |
| **Immich でゴミ箱に入れた写真が「送信済み」のまま** | 送り先の一覧が「ゴミ箱にある」を表示していません（サーバは把握しています）。**「サーバを確かめる」を押すと未送信に戻ります** |
| **「状態を再確認する」を押しても、履歴に「送信」としか出ない** | 再確認と日時の承認は、内部では送信と同じ種類の作業として動きます。**履歴の札はその種類だけで決まる**ので、どれを押しても「送信」と出ます。**押したことが伝わらず「何も起きなかった」と読めます** —— 実際に何が起きたかは、その行の説明文（`再確認: 3 件 / ゴミ箱 0 件 / …`）に出ています |
| **画面に「結合」「ジョブ」といった言葉が出る** | 画面の文言は「つなぐ」「作業の履歴」に揃えてありますが、**サーバが返す説明文だけが内部の言い方のまま**です |
| **操作バーが画面の下端に貼り付かない** | 内容が短くて巻けない画面では、**画面の下端ではなく内容の直後**に出ます |

## つなぐ・送る

| 症状 | 何が起きているか |
| --- | --- |
| **つないだ動画の撮影日時が「つないだ時刻」になる** | 出力の器に書かれた時刻をそのまま読むため、元の撮影時刻ではなく変換した時刻が入ることがあります。**設定 › カメラの種類から再計算**すると直ります |
| **音声や映像が落ちた状態でつながる可能性** | 別経路（TS）へ落ちるかどうかの判定は**音声だけ**を見ており、映像は見ていません。実際に落ちた記録はありませんが、塞いでいる範囲は音声だけです |
| **つないでいる最中に出力を消すと、失敗の理由が別のものになる** | データは壊れませんが、**なぜ失敗したかが読めなくなります** |
| **Immich の組（スタック）が重複することがある** | Immich に「無ければ作る」という操作が無いため、こちらが読み直してから作るまでの間に他から組まれると重なります |

## 設定を変えたとき

| 症状 | 何が起きているか |
| --- | --- |
| **カメラの種類を新しくしても、取り込み済みの撮影日時が直らない** | 既存のファイルは取り込んだときの版のまま残ります。**設定 › カメラの種類から再計算**してください。ただし**確定済みの公開名と、ファイル自体の更新時刻は再計算でも直りません** |
| **リセットの「作業の記録」を消すと、取り込みの控えも消える** | 公開が終わった取り込みの控えは作業の記録が掴んでいるため、同じ段で消えます。**取り込んだファイル自体は消えません** |
